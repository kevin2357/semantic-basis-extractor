# Bre Reference Decks

Bre's corpus preserves the longest editorial development history: early schema
examples, failed and improving rewrites, voice-specific revisions, website
schema migrations, the current gold-standard deck, and later SBE experiments.

`20260727-gold-standard` is the present editorial gold reference. Earlier
versions are negative, intermediate, or migration references rather than
approved examples.

Bre's original birth details and breed were not recoverable from an existing
`params.json`. Her repository params therefore preserve only known identity and
pronoun values and mark the remaining fields unknown.

Ten early artifacts predate the four-summary schema, and the oldest legacy
sample contains 26 rather than 50 cards. `selected-authoring-packet.json` is a
current QA companion and does not purport to be their historical source packet.
