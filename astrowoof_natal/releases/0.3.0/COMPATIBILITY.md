# AstroWoof Natal Authoring 0.3.0 Compatibility

The wheel is dependency-free, `py3-none-any`, and requires Python 3.11 or newer.
The qualified upstream tuple remains AGF 0.6.0, SPC 0.10.0, projected graph 1.3.0,
and pyswisseph 2.10.3.2 where live calculation is required.

Existing extraction, scoring, identity, disclosure, spend, critic, delivery, and
provenance contracts remain compatible. Operator run v0.9 and restoration at one
stable logical absolute path remain authoritative.

The lifecycle contracts are additive public interfaces. They apply to exact-time
v0.9 workspaces. Legacy paid runs continue to fail closed unless migrated through a
supported path.

Events are non-authoritative and may be lost, duplicated, delayed, or reordered.
Consumers determine lifecycle truth from inspection, denial, closeout, native state,
and snapshots—not events.

Closeout uses a verified recoverable multi-file protocol and does not claim
filesystem-wide atomicity. API leases, cross-run reservations, quotas, circuit
breakers, entitlements, billing reconciliation, persisted HTTP status, and cleanup
authority remain API-owned.
