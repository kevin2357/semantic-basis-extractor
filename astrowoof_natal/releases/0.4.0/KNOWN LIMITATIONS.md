# Known Limitations - 0.4.0 Candidate

- Only facts invariant across the complete normalized birth interval may become
  ordinary authored claims. Conditional and alternative narratives are deferred.
- If fewer than fifty invariant claims exist, the run fails explicitly; it does not
  weaken the epistemic standard or silently shrink the deck.
- Interval width and evaluation count are upstream proof context, not SBE scoring
  inputs. SBE does not reconstruct a midpoint, representative instant, exact
  placement, house, angle, orb, strength, probability, or confidence.
- The supplied full-scale end-to-end fixture is one four-hour interval. SPC's
  released 1/24/48-hour matrix proves route equivalence, not three additional SBE
  full-scale deck fixtures.
- Bounded OpenAI authoring currently supports interactive resumable Responses only.
  Batch submission fails closed until a real Batch adapter and tests exist.
- The provider API cannot guarantee whether an identity-less interrupted POST was
  accepted. Such work remains machine-classified ambiguous and requires external
  reconciliation; deterministic local keys are not claimed as proof.
- Workspace restore requires the original stable logical absolute path.
- API-owned responsibilities remain transactional cross-run reservations, account
  quotas, global circuit breakers, leases/fencing, product entitlements, billing
  reconciliation, persisted HTTP status, storage custody, and cleanup authority.
- Unknown-time claim suppression, variable basis sizes, Quick/Complete redesign,
  broader exact scoring redesign, bounded Synastry/Transit, frontend presentation,
  and critic product policy are deferred.
