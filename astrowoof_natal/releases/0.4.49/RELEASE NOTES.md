# AstroWoof Natal Authoring 0.4.49

SBE 0.4.49 corrects the prepared-polish external-authority handoff. A final-QA
warning remains provisional only when it joins exactly to the same subject's
current interactive polish attempt and its unique providerless `PREPARED`
action. That action is then exposed through the existing ordinary
`external_authority_request.v2` boundary.

Committed terminal evidence remains dominant. Stale, mismatched, unrelated,
Batch, bounded, provider-bound, authorized, and consumed evidence cannot use the
exception. The release adds a closed, provider-free packaged qualification
command and schema for this boundary.

The final committed source identity, controlled build epoch, wheel SHA-256, and
installed qualification result are recorded in the sprint release evidence.
