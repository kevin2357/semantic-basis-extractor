# AstroWoof Natal Authoring 0.4.29

SBE 0.4.29 adds the public lifecycle v0.8 retry-lineage and mixed-custody
contract. It gives consumers stable logical retry-attempt identity, refuses
duplicate persisted lineage, preserves provider-custody precedence, and exposes
a typed post-custody review disposition without permitting new provider work.

The release includes packaged schemas, readers, sanitized fixtures, and a
provider-free installed-wheel qualification for exact and bounded interactive
routes. Batch topology remains explicitly deferred.

The wheel is built from source commit `f6a045bc4d49f624058e4d2ec30f6199b8bb5c82`,
requires `semantic-projection-core==0.11.1`, and has SHA-256
`25b35b74b35c65e4bce97f7050e5579d6f802aad944569954e50b7db054c2726`.
