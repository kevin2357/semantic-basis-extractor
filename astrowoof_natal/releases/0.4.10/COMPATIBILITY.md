# SBE 0.4.10 Compatibility

- Python: 3.11 or newer.
- Direct dependency: Semantic Projection Core 0.11.0.
- Qualified upstream identities remain AGF 0.8.1 and SPC 0.11.0.
- Existing exact/bounded, interactive/Batch, lifecycle, capacity, spend, snapshot,
  and native-transition contracts are unchanged from SBE 0.4.9.
- New additive contract:
  `astrowoof.response_retrieval_diagnostic.v1`.
- New additive entry point: `astrowoof-inspect-response`.
