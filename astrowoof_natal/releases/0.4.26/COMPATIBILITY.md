# SBE 0.4.26 Compatibility

- Python: 3.11 or newer.
- Semantic Projection Core: exactly 0.11.1.
- Existing lifecycle, provider-spend, external-authority, retirement, accounting,
  and native-transition contracts remain supported.
- Adversarial qualification artifacts are additive public contracts and are never
  production authority.
- Historical adversarial fixtures retain the package version that created their
  immutable bytes; that fixture provenance is not the installed package version.
