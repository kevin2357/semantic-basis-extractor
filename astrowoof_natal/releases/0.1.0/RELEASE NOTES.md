# AstroWoof Natal Authoring 0.1.0

This is the first versioned runtime release of AstroWoof's projected natal
semantic-basis extraction and LLM authoring pipeline.

## Included

- deterministic extraction from four SPC canine projected-chart contexts;
- ranked 50-claim selection with mandatory natal placements and synthesized
  claims;
- six stratified, bounded authoring passes plus full-chart summaries;
- compact whole-chart context and packaged editorial guidance;
- OpenAI Responses and Batch execution with detach/resume;
- cost-optimized initial/retry/polish routing and complete accounting;
- opaque pass acceptance, constrained metadata repair, and cumulative creative
  retry feedback;
- dynamic section-scoped theme registries with titles, navigation labels,
  emojis, order, and optional subtitles;
- assembly, structural validation, whole-deck lint, and sparse polish;
- durable operator state and redacted public polling state;
- runtime/resource/input/model/QA/delivery provenance and SHA-256 identities;
- five-file per-subject delivery packages; and
- a self-contained installed-runtime smoke command with packaged fixtures.

## Verification

- 118 deterministic repository tests passed.
- Two final wheel builds were byte-identical.
- Fresh installed-wheel smoke passed outside the source tree.
- A controlled live Ella run completed all six passes on attempt 1, passed
  final validation and zero-warning lint after sparse polish, and cost an
  estimated `$0.43773973`.
