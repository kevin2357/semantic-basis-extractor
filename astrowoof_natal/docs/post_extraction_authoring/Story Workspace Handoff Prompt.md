# Story Workspace Handoff Prompt v0.5.1

Author the supplied AstroWoof story workspace.

Start by reading `AUTHORING BRIEF.md` and `DOG DETAILS.md`. Read
`FULL CHART BASIS.md` in full, then complete every marked field in
`WRITE WHOLE DOG PROFILE.md`. This profile is the shared understanding of the
dog for all subsequent writing.

Next, process the numbered directories under `cards/` in order. For each one:

1. read `CLAIM AND EVIDENCE.md`;
2. complete the Editorial Plan in `WRITE THIS CARD.md`;
3. write all nine renderings, practical guidance, humor, filters, and any
   requested theme group;
4. replace every `__WRITE__` placeholder while preserving field markers;
5. finish the file before opening the next directory.

Before each story, set aside prior wording, sentence structures, scenes, jokes,
and rhetorical approach. Retain the whole-dog characterization and semantic
memory of completed stories so the dog remains coherent and neighboring stories
do not repeat one another.

When every supplied directory is complete, return the entire authored
workspace as a ZIP archive.

Begin with the whole-dog profile.
