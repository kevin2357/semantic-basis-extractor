# Story Workspace Handoff Prompt v0.5.0

Author the supplied AstroWoof story workspace.

Read `AUTHORING BRIEF.md` and `WHOLE DOG CONTEXT.md`. Then process the numbered
directories under `cards/` in order.

For each directory:

1. read `CLAIM AND EVIDENCE.md`;
2. complete the Editorial Plan privately in `WRITE THIS CARD.md`;
3. write all nine renderings, practical guidance, humor, filters, and any
   requested theme group;
4. replace every `__WRITE__` placeholder while preserving field markers;
5. finish that file before opening the next directory.

These are independent miniature writing assignments, not rows in a bulk
template. Compose reader-facing language directly. Do not use scripts,
templates, interpolation, seed words, priority numbers, or phrase rotation to
generate prose.

When every supplied story directory is complete, return the entire authored
workspace as a ZIP archive. Do not convert it to JSON.

Begin by opening the workspace and writing the first story.
