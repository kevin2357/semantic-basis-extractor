## Model contract offered for the joint Gate B artifact

The API model admits only three final proof classes:

1. exact cooperative safe-stop + API-parent exit;
2. exact API-parent child/process-group exit; or
3. exact platform replacement with no-new-child fence, old-boot
   retirement/no-overlap, new-boot readback, and collateral-safe inventory.

It separately represents child liveness, target allocation, ordinary and
operator leases, ordinary claimability, retained provider custody, and an
independent global-budget block. Final quarantine releases only the target's
scheduling custody and requires peer admission. Unresolved escalation retains
capacity and names the next proof. Ordinary-result precedence is a separate
non-quarantine result.
