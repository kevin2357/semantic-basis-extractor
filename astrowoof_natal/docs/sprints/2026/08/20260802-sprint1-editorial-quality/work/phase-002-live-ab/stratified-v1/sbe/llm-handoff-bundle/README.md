# AstroWoof Story Workspace Handoff

Each pass directory is a self-contained Markdown authoring assignment. In split layout, passes 1–5 each contain ten stories and pass 6 contains the four full-chart summaries. An attach-ready ZIP is generated beside every pass directory. Open each ZIP in its own temporary chat, read that pass's `START HERE.md`, and return the completed pass directory as a ZIP archive. The six passes may run simultaneously.
