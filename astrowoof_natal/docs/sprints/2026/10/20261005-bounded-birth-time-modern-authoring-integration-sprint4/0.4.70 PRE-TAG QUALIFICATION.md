## Gate rationale

This is an expanded focused release gate, not a broad-suite release. The
bounded route's callers and public behavior are enumerated and directly
covered: new bounded CLI/eligibility, lifecycle/provider behavior,
profile/prompt resolution, package data, installed runtime, and the joined API
ingress/result/receipt paths. Existing exact-route behavior is covered by the
API command matrix and is unchanged by the bounded-only selectors. The broad
suite is therefore intentionally not rerun; its omission requires consumer
review and owner acceptance before publication.
