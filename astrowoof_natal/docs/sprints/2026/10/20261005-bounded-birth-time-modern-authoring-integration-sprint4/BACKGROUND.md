# Bounded Birth-Time Modern Authoring Integration Sprint 4

## Purpose

Bring the existing conservative bounded-authoring capability into SBE's current
AstroWoof runtime-profile, prompt-release, sealed API handoff, terminal
receipt, and observability architecture. This is an integration sprint, not a
replacement for the already qualified bounded semantic policy.

## Alpha contract

Bounded input arrives from API only after AGF/SPC evaluation as a sealed,
four-context, invariant projection family. SBE must author only
dependency-closed invariant facts; variable/conditional/unavailable/inconclusive
facts must not enter claims or provider prompts. A bounded delivery still
requires 50 cards, including the current public general/handler/direct/hybrid
presentation contract.

If a sealed bounded source cannot produce 50 eligible stable cards, emit the
distinct bounded eligibility outcome required by API rather than attempting a
provider retry with identical deterministic inputs. A later product decision
may revisit a smaller deck only after real evidence and reader qualification.

Full-day unknown uses the ordinary bounded family, not a special authoring
route. SBE must validate all artifact/profile/prompt/disposition identities
locally and fail closed before any provider work.

## Dependencies

API Sprint 128 Gate A defines the immutable bounded birth/profile contract.
API Sprint 128 Gate B supplies a real deterministic four-context evidence
packet. This sprint's candidate output/receipt is required by API Sprint 128
Slices 2–3 and its Gate C.
