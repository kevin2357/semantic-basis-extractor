# 0.4.70 release lock

## Scope and gate selection

This release introduces the bounded-birth-time authoring route: its immutable
processing profile and bounded prompt release, bounded CLI and eligibility
command-result contract, and bounded lifecycle/provider handling.  It changes
public API/SBE contracts and packaged resources, so the qualification is an
expanded focused provider-free matrix plus a joined installed-wheel API replay;
the broad suite is intentionally not rerun.  The affected production callers,
route cells, and negative controls are enumerated by the bounded sprint and
the API Gate C evidence below.

The bounded route is not being deployed, activated, or authorized for
provider-backed work by this release.
